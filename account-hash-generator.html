Big Tiff — Account Hash Generator

Runs entirely in your browser. Passwords are never sent anywhere — only a one-way salted hash leaves this page, which is what goes in accounts.json.

accounts.json to commit

Copy this whole block into accounts.json in the big-tiff-data repo (replace the file's contents), then commit.

{
  "schemaVersion": 1,
  "hash": { "algo": "PBKDF2-SHA256", "iterations": 100000, "keyLenBits": 256 },
  "users": []
}

How to use

  1. Add each account above (at least ericap as primary, and any viewers such as aaronf).
  2. Copy the generated accounts.json block.
  3. In the big-tiff-data repo, open accounts.json, replace its contents, and commit.
  4. That's it — logins will work against these hashes. To change a password later, re-add that username here and re-commit.

This is a soft gate, not strong security (see the repo README). Use decent passwords anyway.
